# Native control construction carriers

`manifest.json` orders the nineteen Windows XAXEDIT1 records after the previous
experimental source. Each record has an exact base root and requires native
verification. `fixtures.json` records the separate native fixture replays.

Canonical stores under `native/candidates/20261111-control/` are application
source. Full `01-` through `12-` batch carriers retain the exact native authoring
operations. Rootless helper `.batch` files are construction fragments; do not
concatenate or apply them without the corresponding full carrier's entity
selectors, definitions, labels and ownership order.

Schema-prefix and capability-chunk stages are construction intermediates. They
were not installed or presented as working runtime checkpoints. Only completed
canonical checkpoints carry the runtime evidence recorded by the evidence index.
Verification alone is not JSON-framing or protocol acceptance.

Authoring used the recorded Linux native seed. Verification, replay and builds
used the unchanged pinned Windows seed. No foreign implementation, canonical
graph generator or runtime helper is added here.
